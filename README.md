# Trade Desk

A fantasy sports trade analyzer that runs entirely in your browser.

- **Sleeper:** enter your username to sync every NFL and NBA league, including rosters, records, injuries, taxi/IR and dynasty draft picks.
- **ESPN:** connect public leagues (football, basketball, baseball, hockey) by league ID.
- **Yahoo & others:** import rosters from screenshots or pasted text.
- **Analysis:** Claude grades trades, checks the latest news, suggests counter-offers and finds trade ideas across your league. This needs your own Anthropic API key, which is stored only in your browser.
